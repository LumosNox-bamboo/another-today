# 可选 AI 陪伴

游戏无需 API 也能正常运行。AI 是可选表达层：它可以基于当前人物的性格、状态与真实记录，用更自然的方式聊天和回顾；游戏的活动、金钱、关系、奖励和剧情结果继续由本地模拟结算。

## 在网站启用

1. 打开「设置 → 可选 AI 陪伴」。
2. 填写自己的 OpenAI 兼容 **Chat Completions** API 基础地址、模型 ID、API Key。地址例如 `https://你的服务/v1`；也接受完整的 `/chat/completions` 地址。
3. 确认允许发送内容，点「测试连接」。测试只发一条问候，不发游戏资料；服务仍可能计费。
4. 点「保存并开启 AI」。原来的聊天按钮现在会请求 AI，等待期间只显示“正在输入”，成功后显示 AI 回复；失败时才显示本地回复。

服务必须支持 HTTPS、`POST /chat/completions` 和浏览器跨域访问（CORS）。跨域预检需要允许网站来源、POST、Content-Type 和 Authorization；Authorization 应明确列出，不能仅依赖请求头通配符。纯 GitHub Pages 页面无法绕过服务端的 CORS 限制，遇到此问题需要提供商支持，或玩家自己的受信任代理。

OpenAI 新模型可选择 `max_completion_tokens`，其他兼容服务通常使用 `max_tokens`。当前每次上限为 600 tokens，部分推理模型可能将预算用在内部推理而返回空内容；这种情况会回到本地回复，建议选用适合短文本聊天的模型。未实现 Responses、工具调用、流式输出、图片或语音接口。

## 六种入口

| 功能 | 入口 | 依据 |
| --- | --- | --- |
| 聊天 | 今天 → 聊聊天 | 当前人物、最近实际事件、本次短对话 |
| 主动分享 | 今天 → 小镇来信 → 听 TA 多说一点 | 这条已发生的分享 |
| 小纸条 | 顶部小纸条 → 拆开 AI 纸条 | 原纸条和人物状态 |
| 日记回顾 | 双人日记 → 听 TA 回顾这一天 | 所选日期的角色日记/事件 |
| 共同活动交流 | 世界 → 街区近况 → 一起做过的事 | 玩家确认的内容、当前人物的实际参与 |
| 创作灵感 | 世界 → 礼物与作品 | 当前兴趣与已完成作品；生成未来构想 |

自动表达默认关闭。开启后，仅在新分享或最新纸条可见时尝试生成；每天最多 3 次，间隔至少 10 分钟。专注、免打扰、通知关闭和云存档交接期间不自动调用。生成不会额外弹通知，不增加玩家回应义务。

## 存储、隐私与费用

- API Key 默认仅保留在这次打开期间。勾选「记住本机 Key」后会明文保存在此浏览器的独立 localStorage 项中，不是安全密钥库；公共设备不应勾选。
- API 设置、Key、调用计数和聊天生成结果不进入游戏世界存档，也不进入云同步或 JSON 导出。清除配置会停止当前请求并移除本机 Key；调用计数保留，避免清除配置绕过当日上限。
- 请求包含正在发送的聊天/所选内容，以及当前人物的姓名、年龄、职业、兴趣、目标、人格、当前活动和需求状态、最多五条近期事件与四名已认识的 NPC。不会上传完整存档、隐藏秘密、玩家日记全文或其他人物私聊。
- 「额外附带最近记忆」默认关闭，开启后额外发送当前人物保存的最多五条玩家记忆。当前发送的聊天或主动选中的纸条/共同活动资料本身，也可能包含玩家现实信息；勾选发送许可前请确认服务可信。
- 对话历史最多八条短消息；本地回退回复不作为 AI 历史发送。切换人物、替换世界或修改 API 设置会清空本页聊天历史，停止未完成的聊天请求。
- AI 表达只在本次页面中展示和缓存，不写成真实事件、长期记忆、完成的作品或奖励。原始记录始终保留。语言模型仍可能表达不准确，提示词约束不是事实验证器。
- 默认本机每天最多 30 次请求，可调为 1–100 次；连接测试和失败请求也计数。这个本地计数是便利限制，不是服务商账单的硬上限：其他设备、并发标签页或清除浏览器数据可能独立计数，仍需在 API 服务端设置预算。
- 每页同时最多一个请求，25 秒超时，不自动重试；主动聊天可取消等待。服务的日志保留与数据政策由所选提供商决定。

## 验证与限制

单元与浏览器测试使用模拟 API，覆盖离线零请求、权限确认、Key 分离、成功/失败/超时/取消、预算、人物切换、共同活动归属、五类扩展入口、免打扰与专注静默。没有使用真实 Key 做付费模型验证；实际提供商的连通性和表达质量要由网站中的连接测试和实际聊天确认。

接口依据：[OpenAI Chat Completions 创建接口](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。采用兼容接口以支持玩家自选服务；未来若统一为朋友提供 Key，需要另建受控服务器代理，不能将共享 Key 放进公开网页。

开启 AI 时，纸条仅展示生成正文，等待或失败时不会同时显示本地纸条；未启用 AI 时继续使用本地内容。家庭成员按最久未写信优先轮流提供纸条，受共享每日通知预算约束，不要求切换主控才能获得机会。
