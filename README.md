# 另一个今天 · Another Today

> 你在过你的今天，TA 也在过 TA 的今天。

一个真正可离线运行的像素桌面人生观察游戏。创建人物之后，TA 会自己吃饭、睡觉、工作、读书、散步、与居民相遇。关闭应用后，下次打开按实际经过时间结算，并生成回归摘要。

这是 **0.3「走远一点」可玩版**，不是完整商业发行版。完整玩法、限制与验证记录见下文。无需账号、无需 API Key。网页首次打开需联网，离线资源就绪后可离线启动；桌面版可离线启动。

## 直接游玩

**[点击这里，直接在线玩](https://lumosnox-bamboo.github.io/another-today/)** · 无需下载、无需注册。电脑和手机浏览器均可打开。

每个人的进度保存在自己的浏览器中，不会上传到 GitHub；换设备不会自动同步。可在“设置”中导出 / 导入 JSON 存档。清除网站数据会删除本机进度和离线缓存，请先导出备份。

### 安卓和 iPhone 安装

这是可以添加到主屏幕的 **PWA 网页 App**，无需下载 APK 或通过 App Store。

1. 用手机浏览器打开上面的游玩链接，联网加载一次，在游戏“设置 → 装进口袋”确认“离线资源已就绪”。
2. **安卓 Chrome**：浏览器菜单 →“安装应用”或“添加到主屏幕”；支持时游戏设置里也会显示安装按钮。
3. **iPhone / iPad Safari**：分享按钮 →“添加到主屏幕”→“添加”。如果出现“作为网页 App 打开”，请开启。
4. 以后点击主屏幕图标进入，可在没有网络时继续玩。微信内置浏览器请先选择“在浏览器中打开”。

安装前建议导出存档。部分系统会将浏览器与主屏幕 App 的存储分开；如果进入后没有原来的角色，请导入存档。卸载、系统回收存储或清理网站数据后，可能需要联网重载及恢复备份。游戏没有账号同步；关闭后不会常驻后台，下次进入时补算离线生活。

更新会在联网打开时下载；出现“新版已下载”后，保存并关闭所有游戏标签页及 App 窗口，下次打开使用新版。不会为了更新强制刷新正在玩的页面。

原生 Android / iOS 安装包和微信小程序尚未发布。后续可复用模拟引擎：原生包需要包装与设备测试，上架需要对应开发者账号及审核；微信小游戏需要适配微信运行环境、渲染、存储与文件导入导出，不能直接把现有网页当成小游戏上传。技术与测试说明见 [手机安装说明](docs/MOBILE.md)。

### 桌面版

桌面包可通过下方命令自行构建，产物位于 `release/`（不提交到 Git 仓库）：

- **macOS Apple Silicon**：当前源码构建后生成 `Another Today-0.3.0-arm64-mac.zip`，解压后打开 `Another Today.app`。已有旧安装包不会自动升级。
- **Windows x64**：当前源码构建后生成 `Another Today-0.3.0-win.zip`，完整解压到普通文件夹，双击 `Another Today.exe`。必须保留旁边的 `resources`、DLL 等文件。无需 Node.js 或安装依赖。

本地构建没有 Apple/Windows 商业签名证书。macOS 首次打开如被系统拦截，可在系统设置的“隐私与安全性”中对你自己构建的应用选择“仍要打开”。不要关闭系统整体安全保护。Windows 包在 macOS 交叉构建，尚未在 Windows 真机验证。

应用不会随系统开机启动，也不会在关闭后真正保持后台进程；“离线生活”是下次启动时的确定性补算。没有强迫签到机制。

新增 **芦苇河岸、玻璃温室、旧物工坊、周末集市、纸灯小剧场、山坡观测站** 六处像素场景。地点遵守开放时间、周末和维修安排，小人与居民会按作息和兴趣自主前往。

在 **世界 → 散步与见闻** 查看实际到访与 24 种见闻；建议去处不会传送小人，也不会打断吃饭、睡觉或工作。纪念可以展示在公寓里。新增 **120 个事件、十条长故事、30 种礼物、18 种新闻**，12 组小故事有真实前因和数日间隔。普通旧剧情等待三游戏日后角色会自行决定，重大人生选择仍等你有空。

旧存档直接继续使用。具体玩法和验证见 [0.3 扩展说明与验收](docs/OUTSKIRTS.md)。0.2 报告、审计和截图作为历史基线保留。

## 开始后的玩法

1. 创建姓名、年龄、身份、职业、兴趣和住房；调整 10 维人格、发色、肤色、服装、初始积蓄与愿望。
2. 在“今天”观察世界。默认 4 倍，支持暂停、1 倍、4 倍、12 倍。现实日期与游戏日期分别显示。
3. 场景按钮只切换观察视角，不会把人物强行传送过去。“跟随 TA”会回到人物所在场景。
4. 如果想快速看故事，在“设置”使用“快进 6 小时”。这会真正推进生活并保存。
5. 点击公寓里的书架、书桌、植物等，查看物件记忆。
6. 打开“人物”“关系”“人生档案”，查看性格变化、独立居民、五维关系、故事因果和收支。
7. “和 TA 聊聊天”使用离线规则与事实检索。默认不保存聊天原文；只有主动勾选“允许记住这条分享”的内容进入长期记忆。“不要记住”等明确拒绝优先于勾选框。
8. “一起专注”记录计划。返回时间不会自动认定为学习时长；实际时长和完成内容由你确认。
9. “双人日记”左侧是现实中的你，右侧是游戏中的 TA。玩家日记可手写，也能整理已确认的信息；信息不足时不会凭空补写。游戏日结束自动生成一篇小人日记。
10. 顶栏缩小按钮进入可调整大小、置顶的桌面小窗，并切换到 1 倍陪伴。恢复完整窗口后保留当前倍率。
11. 重大职业、搬家、关系选择在首页等待确认，世界会继续运行。关闭欢迎摘要不会删除历史记录。
12. 可以开启很轻的程序化环境和弦；默认静音。

### 明确的初版边界

- **没有在线大模型连接**，不提供 API Key 输入框。离线聊天是规则与检索，不能当作通用 AI 助手。
- 使用原生 **Canvas 2D 程序化像素绘图**，没有 PixiJS、外部商业美术或完整多方向逐帧精灵。部分动作共用站姿与小道具表现；没有路径障碍寻路。
- 住房目前影响背景记录、初始积蓄/开支与搬家记录，不提供家具拖放、装修编辑或不同房型布局。教育/家庭背景会记录在人物档案，没有完整的专属事件分支。
- 人生目标提供累积进度与完成记录；新增礼物带来的兴趣倾向、愿望与重新尝试。尚无独立出版、完整创业经营、结婚、生育、衰老死亡、复杂考试、家庭树或宠物养成系统。恋爱是有限的事件与多维关系系统。
- NPC 独立生活采用时段计划和日级记忆摘要，不为每个 NPC 运行一套完整的主角模拟。玩家不直接指挥 NPC。
- 完整日志保留最近 1,500 条，日记/玩家日记各最多 400 篇、账本 600 条、性格演化 100 条。人物记忆按重要性整理；已授权玩家记忆最多 150 条，不会被人物记忆挤掉。
- 每个事件链单个世界最多运行一次；普通事件按各自定义冷却，部分有后续的故事片段只发生一次。长时间离线最多处理 30 个游戏日（8,640 个逻辑步），逐日生成日记；超出的时间明确视作休整，不跳过游戏日历、不伪造数年经历。
- 导入存档把现实基准重置为导入时刻，不补算“导出到导入”之间的时间。游戏日期保留不变。
- 网页版用 localStorage 双槽保存，不具有桌面文件 fsync 的可靠性。浏览器 JSON 与桌面带校验的导出格式分开。
- macOS 本机已执行真实桌面端到端测试；Windows 包完成交叉构建，需在目标机器验证。Linux 构建配置已提供，未作发行验证。

## 源码启动

推荐 **Node.js 24 LTS**（项目 `.nvmrc` 指向 24）。Node 26 在 Electron 下载校验依赖中出现提前退出，本项目不将其作为支持的构建环境。

```sh
cd another-today
npm ci
npm run desktop
```

如果当前 npm 环境禁用了依赖安装脚本、提示 Electron 未安装，在 **Node 24** 下执行：

```sh
node node_modules/electron/install.js
npm run desktop
```

开发浏览器预览：

```sh
npm run dev
```

Vite 会打印本地地址。浏览器和桌面版的存档互不影响；小窗/置顶与原生文件对话框只在 Electron 可用。

```sh
npm run test:web           # 网页版桌面 / 手机视口、存档与恢复
```

Windows ZIP 为跨平台构建关闭了可执行文件资源重写，不影响运行；因此 Windows EXE 图标可能仍显示 Electron 默认图标。macOS 应用采用原创像素房屋图标。

## 本地存档

实际位置在游戏“设置”里显示：Electron `app.getPath('userData')/saves`。典型位置：

- macOS：`~/Library/Application Support/another-today/saves/`
- Windows：`%APPDATA%/another-today/saves/`
- Linux：`~/.config/another-today/saves/`

文件为 `world.json` 与 `world.backup.json`。主档损坏时自动读取备份，并明确提示可能丢失最近一次保存后的进度。两个文件都损坏时不悄悄新建世界，会提示导入旧备份。

每 15 秒保存一次，重要操作立即保存，正常退出请求最后一次保存；强制结束进程最多可能丢失最后一个自动保存间隔。桌面存档是本地明文，不是加密保险库。校验和用于发现损坏，不是防篡改签名。导出的存档包含你主动保存的私人信息。未授权聊天不写入存档，也不写入日志。
