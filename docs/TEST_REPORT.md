## 引擎重点断言

- 一次推进与按分钟拆分推进（含非整步长余数）得到完全一致的世界状态。
- 1×、4×、12× 在相同游戏时长下得到一致的事件、金钱、关系与日记。
- 倍率切换先结算旧倍率；暂停期间不推进；系统时钟回拨不会重放已结算时间。
- 相同现实时间戳重复结算不会重复事件、工资或日记。
- 极端离线输入最多模拟 30 个游戏日，需求、资金、日期记录满足结构约束。
- 正常职业夜间睡眠、便利店夜班独立作息，NPC 夜班午夜仍在工作地点。
- 无业者不会触发需要工作身份的事件，无恋人不会触发恋人事件。
- 工资最多每个归属游戏日一次，搬家选择重复调用不会重复扣钱。
- 重大职业/住房选择离线期间保留待确认，世界仍继续运行。
- 不愿意的 NPC 可以拒绝恋爱，不把关系阈值直接当作双方同意。
- 人格变化幅度小、可追溯，默认角色能自主散步、购物和照料植物。
- 至少 150 条不同标题和正文的结构化事件；实际事件库 160 条。
- 15 条故事链逐一通过延迟、中间节点、等待选择、因果引用、结局幂等测试。
- NPC 在没有主角接触的情况下仍形成独立生活记忆。
- 玩家聊天默认不存入长期记忆；明确授权才能保留；拒绝记忆优先；可去重、检索和删除。
- 对“考试没通过”不误作成功庆祝。
- 不把 50 分钟后回到游戏认定为学习了 50 分钟。
- 无真实来源时，玩家日记草稿为空；确认活动后才引用本人确认时长。
- 无效版本、随机种子、时间边界、生成序号和文件校验失败的存档被拒绝。
- 并发保存按顺序写入；主档损坏后从有效备份恢复；两个文件都损坏时报告而不覆盖。

## 桌面完整操作链

1. 从空测试数据目录创建人物并看到动态世界，验证 renderer 无 `require`、启用 contextIsolation 与 sandbox。
2. 打开所有主页面，连续推进一天，查看自动日记，编写并保存真实玩家日记。
3. 无授权消息不进入存档；主动授权后可检索；删除记忆后重启仍不存在。
4. 开始专注、返回、确认实际 20 分钟；切换 420 px 小窗并验证置顶；检查底部按钮完整落在可视窗口内。
5. 模拟关闭 30 分钟，重开后产生准确回归摘要，按 4× 推进约两游戏小时；再次重开不重复结算。
6. 原生存档导出、再次导入、拒绝无效文件；全流程没有捕获到页面错误。

自动测试使用系统临时目录隔离存档，结束后删除测试数据，不使用或覆盖真实玩家存档。

## 平衡审计

可复现命令：`npm run audit:balance`。输入为 `defaultCharacter` 加 10 种初始职业，种子分别为 100–109，初始日期 2026-10-19，逐小时采样，共 30 个游戏日。完整结果保存在 `BALANCE_AUDIT.json`，控制台输出保存在 `BALANCE_AUDIT_RUN.txt`。

发现默认贪心选分过度偏向阅读/创作后，改用带硬性生理优先级的 softmax 选择，并加入洗漱、采购与园艺的时间条件。调整后所有职业都产生了多样日常活动；这是对有限种子的平衡检查，不代表穷尽所有人格组合。

## 实测修复

- macOS 退出时保存请求阻止了原始 quit，需要在保存窗口结束后继续 app.quit；已修复并通过重启测试。
- NPC 夜班被通用午夜“在家”条件覆盖；已调整优先级并增加回归断言。
- 桌面小窗出现通知条时，底部操作超出窗口；改为剩余高度布局并加入可见区域断言。
- 初期 Electron 37 安装脚本在 Node 26 上提前退出，使用 Node 24 完成环境准备；最终交付运行时升级为 Electron 44.9.0，并重新完成桌面验证。
- Windows ZIP 阶段第三方 7zip 工具下载超时；可执行目录构建成功，交付 ZIP 使用本机压缩工具生成，不依赖该下载。

离线聊天不是通用语言模型。初版不含完整婚育、衰老、经营、装修或在线 AI。macOS 构建未使用商业签名或公证；Windows 尚需目标机器验收。功能边界和存档保留上限在 README 中逐项列出。
