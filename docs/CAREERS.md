# 职业与学业路线

在「人物」页查看当前成员的「职业与学业路线」。左侧头像可以切换成员；每人的专业、练习、方向和历史分别保存。

## 本轮内容

保留全部 10 个现有职业选项，提供 29 条实际模拟路线、132 项不同任务，每项有顺利推进和需要返工两种结果，共 264 段结果文案。

| 路线 | 日常示例 | 成长阶段 |
| --- | --- | --- |
| 办公室职员 | 报销核对、周报、纪要、采购、交接、流程改进 | 熟悉业务 → 独立承办 → 项目协调 → 流程改进 |
| 程序员 | 缺陷复现、功能实现、评审、测试、发布、技术债 | 熟悉代码库 → 独立交付 → 模块维护 → 系统设计 |
| 咖啡师 | 开店校准、奶泡、订单确认、高峰分单、盘点、饮品研发 | 跟班练习 → 稳定出品 → 带班协调 → 菜单研发 |
| 便利店店员 | 夜班交接、效期、顾客、收银、配送、交班备忘 | 熟悉夜班 → 独立值班 → 交接带班 → 门店优化 |
| 自由职业者 | 需求、报价、样稿、交付、付款跟进、作品集 | 整理服务 → 完成小单 → 稳定合作 → 建立工作室节奏 |
| 插画师 | 简报、草图、配色、参考授权、修改、成稿输出 | 草图练习 → 独立成稿 → 系列创作 → 个人风格 |
| 作家 | 人物动机、初稿、试读、资料核对、修订、投稿材料 | 建立写作习惯 → 完成初稿 → 修订成篇 → 持续发表 |
| 教师 | 课堂目标、批阅、答疑、材料、教研、学习支持 | 备课磨课 → 独立授课 → 教研协作 → 课程建设 |

大学生支持通识探索与 16 个专业：计算机科学、医学、护理、法学、经济金融、工商管理、汉语言文学、外语、新闻传播、教育学、心理学、建筑学、机械工程、生命科学、艺术设计、音乐。每个方向有四项具体课程任务、三项能力与两个发展方向。

另有小学、中学、待业探索、退休生活四条路线。未成年人使用符合年龄的课程，不能被设置为成人职业；退休年龄继续使用退休路线。未设置专业的成人学生先使用通识探索，不推断旧档人物学过什么。

## 自动生活与实际效果

- 路线参与活动选择和地点选择。成人学生在课程时段主要学习，不再把上课作为付薪工作。紧急需求、休息和已有玩家指令仍有优先权。
- 不同工作有不同日程：咖啡师 7–15 点、教师 8–16 点、办公室与程序员 9–17 点、独立创作和自由职业 10–17 点、便利店夜班 22–6 点。服务职业周一、周二休息，其余工作周末休息。夜班跨零点仍属于开始上班的日期。
- 咖啡师开店校准和店员收银、配送、交班有具体时间窗口，避免凌晨交接和下午开店混淆。夜班 NPC 白天补眠不会被探索安排覆盖。
- 实际开始工作或课程后，主场景与专注现场显示具体任务。完成时增长相应能力；熟练度、性格与压力影响顺利或返工的概率。不会保证每次成功。
- 每条路线的阶段累计门槛是 20、100、300、800 个游戏小时，并至少实践三种任务。旧职业等级保留，新的成长从本次更新后的真实实践开始。收入仍沿用原有简化日结与独立钱包规则。
- 两个发展方向会改变任务权重，仍会轮换练习其他能力。近期任务减重；需要返工也积累少量经验，不把失败当成零价值。
- 中断、未结束或地点不符的活动不结算职业进度。同一活动不重复结算。职业日常结果每天最多记录三条，日记优先收录两条实际实践；阶段成果进入记忆和因果图。
- 与实际同场、同职业的成年 NPC 偶尔交流进度，形成关系变化与署名事件。NPC 的日程和当前计划也使用职业内容。

## 设置与存档

创建成人学生时可选择专业；现有成员在人物页展开「调整职业或专业」，选择后点击「保存职业与专业」。这是玩家明确的设定操作，不是自动求职或录用。

换方向会停止当前活动，撤下旧工作和学习队列；其他生活安排保留。原路线的进度、事件、记忆保留，再切回时可以继续。旧版已存在的自由职业提议仍可处理，但不再给每种职业都生成相同的转自由职业提议。

存档仍为 version 1，新增可选的 character.major、个人 career 和 activity.career。随本地保存、导出、家庭成员切换及云端交接保存，无需更改数据库。没有旧数据时不补造练习或阶段成果。

## 范围

这次扩充复用既有公寓、办公室、咖啡馆、商店和图书馆场景；尚未新增学校、医院或工厂专属地图。医学、护理等是学生课程和模拟训练，不自动取得执业资格。阶段成果不自动授予学历、入职或升任真实管理职务。薪资、合同、税费、考试与学期制度仍是简化模型；未来可以继续围绕这些基础扩充。

## 验证

- `npm test`：职业内容校验、成员隔离、旧档、云交接、阶段成长、非法数据、真实结果和中断行为。
- `npm run audit:careers`：100 个不同种子，各模拟 30 天，覆盖全部 29 条路线，每日保存和重载校验；结果见 `CAREER_AUDIT.json`。
- `npm run audit:living`：原有 100 种子 × 30 天世界与五类人格回归。本次结果独立保存在 `CAREER_WORLD_AUDIT.json`，历史郊外报告不覆盖。
- 浏览器覆盖创建专业、实际快进产生课程、不同成员职业设置、读档与发展方向；桌面与手机截图在 `screenshots/career-paths-v12/`。
